# 😈 Demon Launcher

Русскоязычный Android-лаунчер в огненно-демоническом стиле. Это **настоящее приложение**, а не изображение рабочего стола.

## Возможности

- 24 рабочие иконки настоящих установленных приложений (6 рядов × 4).
- Автоматическая подстановка приложений при первом запуске.
- Запуск приложения одним нажатием.
- **Удерживай иконку**, чтобы заменить её на другое установленное приложение.
- Поиск по всем приложениям и запуск из поиска.
- Демонический тёмно-лавовый фон, пульсирующее свечение и искры.
- Время, дата, русские подписи.
- Кнопка настройки лаунчера по умолчанию.
- Приложения для Android 8+; рассчитано на realme P3 5G (Android 15).
- Без рекламы, трекеров и доступа в интернет.

## Скачать готовый APK

1. Открой вкладку **Actions** в этом репозитории.
2. Выбери последнюю успешную сборку **«Собрать Demon Launcher APK»**.
3. Внизу раздела **Artifacts** нажми **Demon-Launcher-APK**.
4. Распакуй ZIP, установи файл **app-debug.apk** на телефоне.
5. Запусти Demon Launcher и нажми **«Сделать основным»** — выбери его в настройках домашнего экрана.

Если система запрещает установку APK, разово разреши установку из приложения, которым открываешь файл.

### Вернуть обычный рабочий стол

Настройки Android → Приложения → Приложения по умолчанию → Главный экран → выбери прежний системный лаунчер.

> На первом запуске список формируется из реально установленных приложений. Узнаваемые Telegram, ChatGPT, Госуслуги, Яндекс Go и Dota Underlords поднимаются в начало, если обнаружены. Остальные 19 (и любой другой слот) можно назначить удержанием. Порядок 24 иконок из старого скриншота невозможно автоматически восстановить без списка названий.

**Примечание:** APK подписывается стандартным отладочным ключом GitHub Actions. Это установочный тестовый билд, не релиз Play Store.
